OPERATING SYSTEM

FOUNDATIONS

LAYER kernel

Kernel forms an essential part of the operating system that acts as a direct interface between the software applications and the computer’s hardware. It performs the function of allocating important computer resources such as CPU scheduling, memory management, and controlling hardware devices.

  • Runs in kernel mode with access to hardware and memory space of the system

  • Carries out basic functions such as handling the process states, threads, and system calls

  • Maintains stability of the whole system and keeps core functions away from user applications

The device layer employs software applications called device drivers that serve as intermediaries between the OS and peripheral hardware devices. They act as interpreters and hence allow abstraction of the hardware by making it possible for the OS and other applications to communicate with hardware without having to understand its inner workings.

  • Translates high-level commands from the OS into machine-level language that the hardware understands.

  • Makes it possible to incorporate peripheral hardware such as keyboards, mice, printers, and hard drives.

  • Works in tandem with the kernel to perform input and output operations safely.

User Layer refers to the space in which all the normal applications and graphical interfaces exist. The whole layer runs on user mode, and the layer has restrictions when it comes to privileges. This is because the user layer ensures that the user software cannot crash the computer system.

  • Houses the user interface programs like web browsers, media players, and productivity programs.

  • Uses the system calls to ask for resources in the hardware or file system from the kernel.

  • Keeps application errors separate from the operating system.
