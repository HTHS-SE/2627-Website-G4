WHAT IS AN

OPERATING SYSTEM?

An operating system (OS) is a collection of software that manages a computer's hardware and applications by allocating resources, including memory, CPU, input/output devices and file storage.

- IBM, OS Topic

ARCHITECTURE


The architecture of an operating system is used to specify the interaction between the software and hardware of a computer in well-defined, isolated layers. The OS is divided into two levels of execution; user space and kernel space.

  • User Space Layer: Prevents any user application from accessing the hardware directly or accessing the memory that is used by the system to function properly.

  • System Call Interface: This layer is used to create a bridge for user-level application to access the services provided by the kernel.

LAYERS
OF THE OS

kernel

The basic core part of the operating system that controls all major system processes and CPU scheduling along with communication with the hardware.

device

Handles input-output communication through which communication takes place between the system and hardware components using drivers.

user

The user mode is the part of the system where all common applications and graphical interfaces work using system calls.
